## 常见问题排查

### 问题 1: Metal Type 字段显示为空
**可能原因**: 未执行数据迁移 SQL  
**解决方法**: 参考 UPGRADE.md 执行数据迁移脚本

### 问题 2: 创建 Daily Metal Price 时找不到 Metal Type
**可能原因**: 默认数据未加载  
**解决方法**: 
```bash
./odoo-bin -u pos_gold_pricing -d your_db --stop-after-init
```

### 问题 3: CSV 导入失败
**可能原因**: CSV 格式使用旧的 metal_type 字段  
**解决方法**: 更新 CSV 表头为 metal_type_id/id

### 问题 4: 价格计算返回 0
**可能原因**: 
- 没有对应日期的每日金价记录
- Metal Type 未设置或错误

**解决方法**: 
- 检查并创建对应日期的每日金价
- 确认批次的金属类型设置正确
