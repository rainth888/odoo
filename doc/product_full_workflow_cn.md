# Odoo 18 产品库存全流程操作指南

本指南面向使用 Odoo 18 企业版/社区版（中文界面）的业务人员，介绍从产品入库到销售、退货、盘点以及库存统计的完整操作流程。每个环节均给出所需模块、菜单路径以及关键表单字段说明，适用于标准单仓库场景。多仓库、多公司或高级路线配置可在此基础上扩展。

---

## 1. 前置准备

1. **安装模块**（管理员 → `应用`）：
   - `库存（Inventory）`
   - `销售（Sales）`
   - `采购（Purchase）`（如需从供应商采购）
   - `会计（Accounting）`（若需记录发票/账务）
   - 可选：`计量单位（Units of Measure）`、`条码（Barcode）`、`质量（Quality）` 等扩展模块。
2. **启用多单位/批次等功能**（`库存 → 配置 → 设置`）：
   - 勾选“多计量单位”以便选择不同单位。
   - 如需批次/序列号管理，可启用“批次 & 序列号”。
   - 如需多步收货（收货→入库），可启用“高级路线”；本文按默认单步流程说明。
3. **基础主数据**：
   - `库存 → 产品 → 创建`：维护产品名称、类型（库存产品/消耗品/服务）、默认计量单位、采购/销售计价等。
   - `采购 → 供应商`、`销售 → 客户`：维护合作伙伴资料。

---

## 2. 采购入库流程（Receipt / PO）

**业务场景**：从供应商订货并收货入库。

1. **创建采购订单**
   1. 模块：`采购`
   2. 菜单：`采购 → 采购订单 → 创建`
   3. 在表单中：
      - 选择供应商。
      - 填写产品行（产品、数量、计量单位、单价、税率）。
      - 保存并点击`确认订单`，系统生成待收货。
2. **收货入库**
   1. 从采购订单页面点击`收货`（或进入 `库存 → 操作 → 待办 → 收货`）。
   2. 在收货单中：
      - 检查实际到货数量，可根据需要编辑`完成数量`。
      - 如启用批次/序列号，在`详细操作`中填写对应编码。
      - 点击`验证`完成入库，库存数量更新。
3. **生成供应商账单（可选）**
   1. 在采购订单页面点击`创建账单`。
   2. 检查账单内容后`确认`并`登记付款`。

**提示**：若仅需简单入库，可直接使用 `库存 → 操作 → 调拨 → 创建`，选择来源位置（供应商）与目标位置（库存），录入产品和数量后验证。

---

### 2.1 计件与计重产品的主数据配置

**入口**：`库存 → 产品 → 产品`，点击“创建”或编辑现有产品。

1. **通用字段**
   - `产品类型` 选择“库存产品”，以便系统记录库存数量。
   - `产品类别` 建议区分“计件商品”“计重商品”两个类别，以便报表统计。
   - `路线` 根据业务需求启用“购买”，以允许从采购单补货。
2. **计件产品（按数量采购）**
   1. 在`常规信息`页签：
      - `计量单位` 选择“件/个”等数量单位。
      - `采购计量单位` 保持一致（通常同样为“件”）。
      - `销售价格` 或 `成本` 填写每件价格。
   2. 切换至`采购`页签：
      - 在`供应商列表`中添加供应商，`价格`填写“每件采购价”，`最小数量`填写1。
      - 如同一产品存在不同包装（如箱），可通过 `其它` 页签 → `单位转换` 为外箱创建替换单位。
3. **计重产品（按克采购）**
   1. **准备计量单位**：若列表中没有“克 (g)”，先到 `库存 → 配置 → 计量单位`，在“重量”类别下启用`克`，将`精度`设置为 0.01 或业务需要的最小刻度。
   2. 在`常规信息`页签：
      - `计量单位` 选择“克 (g)”或业务常用重量单位；`采购计量单位` 默认跟随，可保持为“克”。
      - `销售价格`/`成本` 根据业务习惯填写“每克价格”，或留空并在采购时录入。
      - 可在`库存`页签维护产品的`重量（公斤）`、`体积`等属性方便物流。
   3. `采购`页签：
      - 在`供应商列表`中为每个供应商设定“价格 = 每克采购价”，并可在描述中备注“到货需称重”。
      - 如供应商按批次提供固定克数，可新增一条“供应商价格”并指定对应`最小数量`（例如500g）。
4. **附加建议**
   - 如需区分计件/计重字段，可在`内部参考`或`条码`中使用前缀（如 `PC-`、`WG-`）。
   - 若公司在销售端仍按件出售计重产品，可启用`多计量单位`，在`单位转换`里配置“1 件 = 50 g”等换算关系。

### 2.2 采购订单录入示例（计件 vs 计重）

1. **创建采购订单**（`采购 → 采购订单 → 创建`）：
   - 选择供应商后，在订单行添加产品。
   - 若是计件产品：
     1. `数量` 填写件数（例如 10 件）。
     2. `单位` 默认是“件”，`单价`自动带出“每件采购价”，可按需修改。
   - 若是计重产品：
     1. `数量` 填写预计采购重量（例如 500 g）。可在下单时根据历史经验先填大致重量。
     2. `单位` 选择“克 (g)”或所设定的重量单位。
     3. `单价` 自动带出“每克采购价”；如按批次议价，可直接改为本次成交价。
     4. 如供应商按公斤计价，可在`单位`改为“千克”，系统会依据单位换算自动计算库存数量。
2. **确认订单后收货**：
   - 在收货单的`详细操作`中：
     - 计件产品直接核对件数，无需额外操作。
     - 计重产品建议将实际称重结果录入`完成数量`（支持保留两位小数），以确保库存数量与实际重量一致。
     - 若存在重量损耗，可保留差异，系统会记录库存调整。
3. **差异处理**：
   - 若采购订单上填写的是预计重量，实际收货重量不同：
     1. 可以在收货时直接修改`完成数量`为实际重量，系统会根据修改后的数量生成会计/库存记录。
     2. 如需保留原单据与实际差异，可在收货后创建`退回`或新增一张补充采购单。
4. **价格控制与报表**：
   - 可在`采购 → 报表 → 采购分析`按产品类别过滤“计件商品”“计重商品”，比较不同计价方式的成本。
   - 若需要按照重量核算成本，请在产品类别中启用自动库存估值并指定正确的`库存账户`和`差异账户`。


## 3. 销售出库流程（Delivery / SO）

**业务场景**：向客户销售商品并发货。

1. **创建销售订单**
   1. 模块：`销售`
   2. 菜单：`销售 → 报价单 → 创建`
   3. 在表单中：
      - 选择客户与有效期。
      - 添加产品行（产品、数量、售价、税金）。
      - 点击`确认`将报价转为销售订单，系统生成待出货单。
2. **交付发货**
   1. 在销售订单页面点击`发货`（或前往 `库存 → 操作 → 待办 → 发货`）。
   2. 在发货单中：
      - 核对`完成数量`是否与实际发货一致，可调整部分发货。
      - 若启用批次/序列号，在`详细操作`中指定。
      - 点击`验证`执行出库，库存数量减少。
3. **开具客户发票（可选）**
   1. 在销售订单点击`创建发票`。
   2. 选择发票类型（标准/退款/预付款），生成草稿发票。
   3. 审批并`登记付款`。

**POS 场景**：若通过POS售货，需在 `POS → 配置 → 销售点` 中设置库存和会计整合。POS确认的订单会生成交付单，可在 `库存 → 操作 → 转运单` 中查看。

## 4. 退货流程（Return）

退货分为两类：客户退货（销售退货）与供应商退货（采购退货）。

### 4.1 客户退货

1. 进入原销售订单或交付单。
2. 在交付单上点击`退回`。
3. 在弹窗中填写退货数量、退回位置（默认退回到库存）。
4. 点击`退回`生成逆向调拨。
5. 打开生成的退货单，核对后点击`验证`完成入库。
6. 如需退款，在原销售订单点击`创建发票`并选择`退款发票`，或在会计模块开具贷项通知单。

### 4.2 供应商退货

1. 打开原采购订单的收货单。
2. 点击`退回`。
3. 填写退货数量，确认目标位置为供应商。
4. `退回`后打开退货单并`验证`，库存扣减。
5. 在采购订单中可创建`退款账单`处理财务。

**注意**：如退货货物需送往质检或损坏仓，可在退货单中修改目标存放库位。

## 5. 库存盘点与调整

### 5.1 快速盘点（即时调整）

1. 模块：`库存`
2. 菜单：`库存 → 操作 → 库存调整`
3. 在列表中点击`新建`或选择现有盘点计划。
4. 设置范围（库存地点、产品、批次等），点击`开始盘点`。
5. 在盘点表中输入实际数量：
   - `理论数量`为系统当前数量。
   - 在`实际数量`列填写实盘结果。
6. 点击`验证`生成库存调整单，系统自动记录差异。

### 5.2 循环盘点/多库位盘点

1. 可在库存设置中启用`库存盘点计划`或使用`条码`模块扫描盘点。
2. 进入 `库存 → 配置 → 库存盘点计划` 创建周期任务，指派员工并设定频率。

## 6. 库存统计与报表

1. **库存概览**：`库存 → 仓库 → 仓库看板`，查看收货、发货、延迟订单等卡片。
2. **当前库存**：
   - `库存 → 报表 → 库存估值`：按产品、地点、批次查看数量与金额。
   - `库存 → 报表 → 仓位库存`：查看各库位存量。
3. **移动分析**：`库存 → 报表 → 库存移动`，过滤特定日期、产品、合作伙伴。
4. **销售/采购分析**：
   - `销售 → 报表 → 销售分析`：按产品/客户查看销量、收入。
   - `采购 → 报表 → 采购分析`：按供应商/产品统计采购情况。
5. **退货追踪**：在库存移动或销售/采购报表中按`操作类型`过滤`退货`。
6. **自定义报表**：使用`数据透视`或`图表`视图添加维度（日期、产品类别、仓库）。

## 7. 常见问题与建议

- **权限控制**：确保相关用户被分配到合适的安全组，如`库存/用户`、`采购/经理`、`销售/经理`等，以访问对应菜单。
- **多步骤仓库**：如需收货→质检→入库等流程，可在`库存 → 配置 → 仓库`中编辑仓库，将`收货`流程改为两步或三步，并按新流程执行调拨。
- **自动化流程**：
  - 可在销售订单上启用`自动确认采购`，由 MTO 或补货规则驱动。
  - 在`库存 → 配置 → 补货规则`设置最小/最大库存，实现自动草拟采购单。
- **盘点差异会计处理**：启用了自动估值的产品，库存调整会生成会计分录；确认相关科目（库存科目、盘盈盘亏科目）已在产品类别中配置。
- **报表导出**：所有列表视图支持`导出`（右上角⚙️ → 导出），可勾选字段输出为 Excel。

---

通过以上步骤，可以在 Odoo 18 中完成产品的入库、销售、退货、盘点和库存分析等标准流程。如需更复杂的场景（委外加工、多公司、多仓库、序列追踪等），建议在对应模块中进一步配置路线与规则。
